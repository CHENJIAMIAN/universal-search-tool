## Ways to contribute

We welcome all types of contribution:
- 🐛 Bug fixes
- ✨ New features
- 📚 Documentation improvements
- 🌐 Internationalization
- 🎨 UI/UX improvements
- 🧪 Testing
- 📦 Packaging and distribution

## How to become a contributor

1. Contribute code by fixing bugs or adding features.
2. Improve the documentation.
3. Report valid issues.
4. Provide useful feedback.
5. Help other users.

## Contributor recognition

Every contributor will receive:
- Attribution in the README
- A mention in release notes
- A special Contributor role
